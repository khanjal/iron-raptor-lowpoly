# lowpoly-assets (working name)

A library of low-poly 3D models that are **generated by Python scripts running in Blender**, not modelled by hand: change a number, rebuild, get a new model. One shared 16 x 16 colour palette, flat shading, no textures to author. It began as the art pipeline of the co-op game Signal Unknown and is being split out so anyone can use it.

Status: **extraction in progress.** The scripts under `art/` are a copy of the game repo's `art/` folder (from its `main`, 2026-10-23); the generic library and the game-specific content are not separated yet. See [NOTES.md](NOTES.md).

What it can make today (see `art/README.md` for the file list): quadruped animals from a description (any species, dog breeds, cat coats), people on a shared humanoid rig with clips, road vehicles in paint jobs and New / Damaged variants, furniture, appliances with doors and drawers that open, a modular building kit, vegetation, ships.

Each model can carry moving parts, sound / light / switch markers and sockets, described in `art/data/interactions.json`.
