# Licences

This project uses two licences, one for the code and one for the models.

| What | Licence | Where |
|---|---|---|
| **Code**: the generator scripts, tools, tests and the site's own code | [MIT](LICENSE) | `art/scripts/`, `tools/`, `tests/`, `site/*.html`, `site/*.js`, `site/*.css` |
| **Models and data**: everything the scripts produce (GLB, FBX, thumbnails), `site/manifest.json`, the data files and the written documentation | [Creative Commons Attribution 4.0 International (CC BY 4.0)](LICENSE-MODELS) | `site/models/`, `site/thumbs/`, `site/manifest.json`, `art/data/` (except the skeleton file below), `docs/`, `README.md` |
| **Third-party material** | its own licence | see [CREDITS.md](CREDITS.md) |

A model is under CC BY 4.0 even though MIT code produced it.

## In plain words
You can use the models in any project, free or commercial: a game, a film, a website, a print. You can change them and share the changed versions. The one condition is **credit**.

## How to credit (CC BY 4.0)
Give credit in a place a reader of your project would look: a credits screen, a README, a store page or a video description. A line like this is enough:

> 3D models by khanjal, from Iron Raptor Lowpoly (https://github.com/khanjal/iron-raptor-lowpoly), licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

- Link to the project and name the licence.
- If you changed a model, say so ("edited from ...").
- You do not need to put the credit on the model or in each file. (Each GLB carries it anyway, in its `asset.copyright` field, and the release zips have a `CREDIT.txt`.)
- If the project's name or address changes, use the current one.

## The code
MIT: keep the copyright notice and the licence text with copies of the code. No credit screen is needed for a game made with models that came out of it; the models' credit above is what applies.

## Notes
- This is a plain statement of intent, not legal advice. The legal texts are the files [LICENSE](LICENSE) and [LICENSE-MODELS](LICENSE-MODELS) (the official CC BY 4.0 legal code from creativecommons.org).
- The copyright holder name in `LICENSE` is the GitHub handle; change it to a legal name or an organisation if you want that instead.
