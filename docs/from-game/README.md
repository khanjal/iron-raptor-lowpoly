# Pulled from the game repo

Snapshot taken 2026-10-23 from the game repo's `origin/main` (70c03262) and its open issues and PRs.
From now on **this repo makes the models** and the game consumes them; the game repo keeps the scenes, runtime code
and gameplay. This folder is the hand-over: what was planned, what is waiting, and what the game still expects of
the models. Nothing here is built; the copies are read-only snapshots (edit them here from now on, the game repo's
copies will go stale).

## What the game expects of the models (keep stable)

The game looks models up by name, so a rework never renames or drops these (quality bar, "Keep what already works"):

- **Ids and file names** (`FD_CheeseWedge_01` stays `FD_CheeseWedge_01`). New variants get new ids.
- **Named moving parts** exported open and listed in `art/data/interactions.json`: `hinge` and `slide` only today
  (`ShipRamp` a hinge, `ShipLeg_n` slides, a carton's `Lid`, appliance doors and drawers).
- **Markers**: `Light_`, `Sound_`, `Switch_`, `Slot_` empties, the terminal lamps `Lamp_Locked` / `Lamp_Ready` /
  `Lamp_Working` (separate objects).
- **Ship dimensions** shared with the game's `FarmsteadLayout.cs`: the `SHIP_*` constants, the doorway, ramp part,
  `foot_anchor`s and colliders of the walkable ships (round deck of radius 5.9 m, 12 wall panels).
- Origin on the floor at the centre of the base; the front faces -Y in Blender; real sizes (the audit checks them).
- The palette is append-only (indices are baked into UVs).
- Models have `_Rotten_` twins today (food, the abandoned houses and the trailer park use them): see #352 below.
