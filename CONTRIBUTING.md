# Contributing

Thank you for looking. There are three ways to help; reporting a problem and suggesting a model need no Blender.

## Report a problem or make a suggestion

[Open an issue](https://github.com/khanjal/lowpoly-assets/issues/new/choose) and pick the form that fits:

| Form | Use it when |
|---|---|
| **Problem with a model** | a model looks wrong, faces the wrong way, has a floating or missing part, or its door, drawer or animation misbehaves |
| **Problem with the asset browser** | the website does not load or a control misbehaves |
| **Suggest a model or an improvement** | you want a new model, a variant, a category or tag, or a browser feature |

Tips for a report that gets fixed quickly:

- Search the [asset browser](https://khanjal.github.io/lowpoly-assets/) and the open issues first.
- Give the **model id** (the `GV_Sedan_01` in the address after `#`), what is wrong and what you expected, a screenshot, and where you saw it (the browser, or an engine and version).
- If it is an engine import, read [Using the models in your engine](README.md#using-the-models-in-your-engine) first: most problems are import settings (axes, nearest-neighbour filtering, mipmaps), and the table says which engines have been tested.
- Issues are public: nothing private, and no files you do not have the right to share. Reference links are fine; copyrighted images and models are not.

Models are generated by scripts, so a good report is often a one-line fix and a rebuild.

## Suggest a model

Real, generic objects in the shared style fit (a wheelbarrow, a park bench, another dog breed). Branded products, characters from other works, and scanned or realistic models do not. Say which kind of the thing you mean, roughly how big it is, what makes it recognisable, and what you would use it for.

## Send a change

1. Open or comment on an issue first for anything large, so work is not wasted.
2. Fork, make a branch (`models/<slug>`, `site/<slug>`, `docs/<slug>` or `fix/<slug>`), and keep the change to one topic.
3. Run the checks (standard library only, no Blender needed):

   ```bash
   python -m unittest discover -s tests -t .
   python tools/check_site.py
   ```

4. Open a pull request using the template. Say what you looked at in the browser (`cd site && python -m http.server 8000`).

Notes for changes to models: they are Python scripts in `art/scripts/` run inside Blender; see [art/README.md](art/README.md) and the README's "How a model is made". The colour palette is **append-only**, an existing model keeps its id, and everything comes from the scripts and the shared palette: no models from other libraries.
